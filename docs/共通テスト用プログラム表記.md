## 記法一覧

### 1. 変数
英字で始まる英数字と `_` の並び。例：`kosu` / `kingaku_kei`

### 2. 配列
**配列名は先頭文字が大文字。** 例：`Tokuten[3]` / `Data[2,4]`（2次元）

> **特に説明がない場合、配列の要素を指定する添字は 0 から始まる。**
>
> ただし令和7年度の本試験では、説明つきで **1 始まり**で出題された実績がある。
> このアプリでは **0 始まりに固定**する（Python / JavaScript と揃えることで
> 3言語の対比が成立するため）。

### 3. 文字列
ダブルクォーテーション `"` で囲む。`+` で連結できる。

```
moji = "I'll be back."
message = "祇園精舎の" + "鐘の声"
```

### 4. 代入文
```
kosu = 3 , kingaku = 300        # カンマ区切りで複数文を1行に書ける
kingaku_goukei = kingaku * kosu
Data = [10,20,30,40,50,60]
Tokuten のすべての値を 0 にする
nyuryoku = 【外部からの入力】
```

### 5. 演算子

| 種類 | 記号 |
|---|---|
| 四則演算 | `+` `-` `*` `/` |
| 整数の除算（商） | `÷` |
| 剰余 | `％` |
| べき乗 | `**` |
| 比較 | `==` `!=` `>` `<` `>=` `<=` |
| 論理 | `and` `or` `not` |

### 6. 関数
```
kazu = 要素数(Data)              # 値を返す
saikoro = 整数(乱数()*6)+1
表示する(Data)                   # 値を返さない
表示する(Kamoku[i],"の得点は",Tensu[i],"です")
```
`表示する` はカンマ区切りで文字列や数値を連結できる。
`表示する` 以外の関数は基本的に問題中に説明がつく。

### 7. 条件分岐

```
もし x < 3 ならば:
｜ x = x + 1
⎿ y = y + 1
```

```
もし x >= 3 ならば:
｜ x = x - 1
そうでなくもし x < 0 ならば:
｜ x = x * 2
そうでなければ:
⎿ y = y * 2
```

### 8. 繰返し

```
x を 0 から 9 まで 1 ずつ増やしながら繰り返す:
⎿ goukei = goukei + Data[x]
```
※「減らしながら」もある

```
n < 10 の間繰り返す:
｜ goukei = goukei + n
⎿ n = n + 1
```

### 9. コメント
`#` 以降はその行の処理対象外。

## ⚠ 罫線記号がこの表記の肝

**`｜` と `⎿` で制御範囲を表し、`⎿` がその制御文の終わりを示す。**

- ブロック内の**最後の行だけ** `⎿`、それ以外は `｜`
- 入れ子はプレフィックスを重ねる（`｜ ｜` / `⎿ ⎿`）
- 実際の文字は **`｜` = U+FF5C（全角縦線）**、**`⎿` = U+23BF**。
  半角 `|` や `└`（U+2514）ではない。コピペ元を間違えないこと

公式例（二分探索）の入れ子の様子：

```
( 7 ) hidari <= migi and owari==0 の間繰り返す:
( 8 ) ｜ aida=(hidari+migi)÷2 #演算子÷は商の整数値を返す
( 9 ) ｜ もし Data[aida]==atai ならば:
(10) ｜ ｜表示する(atai,"は",aida,"番目にありました")
(11) ｜ ｜owari=1
(12) ｜ そうでなくもし Data[aida]<atai ならば:
(13) ｜ ｜hidari=aida+1
(14) ｜ そうでなければ:
(15) ⎿ ⎿ migi=aida-1
```

`(15)` で内側の `もし` と外側の `の間繰り返す` が同時に終わるので `⎿` が2つ並ぶ。

---

## 実装メモ

- 公式例は行番号 `( 1 )` `( 2 )` … を左に添えている。アプリのコードパネルでも
  行番号を表示すると試験の見え方に揃う
- 公式例の変数名は**ローマ字**（`hidari` / `migi` / `aida` / `kazu` / `atai`）。
  Python 対比例も同じ名前を使っている。3言語で変数名を揃えると対比が効く
- `÷` は商の整数値を返す。二分探索の中央値は `aida=(hidari+migi)÷2`
  （Python では `//`、JavaScript では `Math.floor((hidari+migi)/2)`）

## PDF からテキストを取り出す手順（再調査用）

この PDF は CJK の CMap を埋め込んでおらず、`pdftotext` では日本語が落ちる
（`Unknown character collection 'Adobe-Japan1'`）。`pdftoppm` もこの環境には無い。

pdfjs-dist なら取り出せる。プロジェクトに依存を足さず、一時ディレクトリで完結させること。

```bash
cd <一時ディレクトリ>
npm init -y && npm i pdfjs-dist@4.10.38
# getDocument({ data, cMapUrl: "./node_modules/pdfjs-dist/cmaps/", cMapPacked: true })
# で読み、getTextContent() の item.transform[5]（y座標）で行を復元する
```
