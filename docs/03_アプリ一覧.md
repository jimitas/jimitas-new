## 移植対象外のフォルダ

| フォルダ名 | 内容 | 理由 |
|---|---|---|
| motto | 29個のアプリを統合した旧プラットフォーム | 中身を個別移植。フォルダ自体は不要 |
| jimipale | じみパレット（算数アプリ集） | mottoのアプリと重複。中身を個別移植 |
| sakusen | 作戦ボード（HTML静的版） | sakusen-board（Next.js版）に統合 |
| jimitas-app | Next.js 版旧プラットフォーム（実験的） | 各アプリを個別移植するため不要 |
| jimitas-next14 | Next.js 14 版旧プラットフォーム | 同上 |
| jimitas-r5summer | Next.js 13 版旧プラットフォーム | 同上 |
| test | AngularJS 試験的アプリ | 開発中断・移植対象外 |

## 種別の定義

| 種別 | 説明 |
|---|---|
| app | インタラクティブな学習アプリ |
| print | プリント生成ツール |
| tool | 授業支援ツール（タイマー・作戦ボードなど） |

---

## 移植難易度の定義

| 難易度 | 説明 |
|---|---|
| 低 | HTML/CSS/JSをそのままReactに移植できる |
| 中 | 状態管理の設計が必要 |
| 高 | 複雑なロジック・外部ライブラリが必要 |
