- 対象サイト：jimitas.com（Next.js App Router / Vercel）
- 開発方法：Claude Code によるローカル開発
- 版：v1.0（確定）　2026-10-25
- 改訂：v1.1　2026-10-26　授業スライドの起点を a = 2 → a = 1 に変更したのに合わせ、初期値・数値例・受け入れ基準 1・2 の値を更新。
  あわせて ①② の最初の表示範囲を狭めた（a = 1 で横 0〜2.4・縦 0〜4.8。2点を結ぶ直線と曲線のすき間 h²/4 を大きく見せるため）

## 1. 目的

平均変化率の2点のうち一方（x = a + h）を x = a に近づけていくと、**2点を結ぶ直線**の傾きが**接線の傾き**に近づくことを、**アニメーションで目で見て**理解させる。

そのうえで、

1. 平均変化率 ＝ 2点を結ぶ直線の傾き
2. x = a における微分係数 ＝ h → 0 としたときの平均変化率の行き先 ＝ **接線の傾き**
3. 導関数 ＝ 各点の接線の傾きを x の関数として集めたもの、とその計算（公式）

の3段階を一本の流れとして体験できるようにする。

### 1.1 用語の方針

教科書の「割線」という語は生徒になじみがないため、画面上では使わない。

| 対象 | 画面での呼び方 | グラフ上のラベル |
|---|---|---|
| 2点A, B を通る直線 | **2点を結ぶ直線** | 「傾き＝平均変化率 ○○」 |
| x = a での接線 | **接線** | 「傾き＝微分係数 ○○」 |

- 「平均変化率」は**傾きの値**の名前として使い、直線そのものの名前にはしない（「平均変化率が接線になる」という誤った言い方を避けるため）。
- 「記号で」表示時のみ、補足として「（教科書では割線ともいう）」を1か所だけ添える。

### 1.2 授業との接続

数学Ⅱスクーリング（50分・4〜5名・予備知識なし）のスライド「円の面積と円周のひみつ」②微分パートと**同じ数値例**を使う。

| スライド | 内容 | アプリでの再現 |
|---|---|---|
| 9 | x 秒で x² m 進む。1秒の瞬間の速さは？ | 初期状態：f(x) = x²、a = 1 |
| 10–11 | 1→2, 1→1.5, 1→1.1, 1→1.01 の平均の速さ 3, 2.5, 2.1, 2.01 | h = 1, 0.5, 0.1, 0.01 の記録表が同じ値になる |
| 12 | 2点を結んだ線の傾き＝平均変化率 | 2点を結ぶ直線の表示 |
| 13 | 2点が重なった線＝接線。x² を微分すると 2x | 接線表示・導関数グラフ 2x |

## 2. 利用者と利用場面

授業での使い方は次の2段階。

1. **教員がPCで実演**（プロジェクタ投影）：h → 0 のアニメーションを見せ、「2点を結ぶ直線の傾きが接線の傾きになる」ことを理解させる。**この実演が最重要の場面。**

## 3. 画面構成

1ページ内に**3つのステップ（タブ）**を持つ。上から順に進む流れを基本とし、タブで自由に行き来できる。**初期表示はステップ②**ではなく①とするが、②へ1クリックで行けること。

```
[ ① 平均変化率 ] [ ② 微分係数（接線の傾き） ] [ ③ 導関数 ]

┌───────────────────────────┬──────────────────┐
│                           │  関数の選択       │
│        グラフ領域           │  数値パネル       │
│   （SVG、座標平面）          │  操作ボタン       │
│                           │  記録表           │
└───────────────────────────┴──────────────────┘
          （スマホでは縦に積む：グラフ → パネル）
```

### 3.1 共通要素

- **関数の選択**（全タブ共通、選択はタブ間で保持）
  - プリセット：`x²`（初期値）、`x³`、`-x² + 4x`、`x³ - 3x`、`2x² - 3x + 1`
  - 自作：3次以下の多項式 `c₃x³ + c₂x² + c₁x + c₀` の係数を入力（整数・小数、-10〜10 程度）
- **表示レベル切替**（ヘッダー付近に常時表示）：
  - 「ことばで」（初期値）：平均の速さ／平均変化率、瞬間の速さ／接線の傾き など、記号を最小限にした表示（スライドと同じ語彙）
  - 「記号で」：`Δy/Δx`、`(f(a+h) − f(a))/h`、`lim_{h→0}`、`f'(a)`、`f'(x)` を数式表示
- **文脈ラベル切替**（P1）：「x, y」⇔「時間（秒）, 距離（m）」。スライド9の運動の例と結びつけるため。
- **グラフ**：
  - 軸・目盛り・格子、ズーム（ボタン＋ピンチ/ホイール）、パン、「全体表示に戻す」
  - 曲線は十分な分割数でなめらかに描画

### 3.2 配色（CUD 準拠・意味で色を固定）

| 要素 | 色の役割 | 備考 |
|---|---|---|
| 関数 y = f(x) | 黒／濃いグレー | |
| 点A（x = a） | 青 | |
| 点B（x = a + h） | オレンジ | |
| 2点を結ぶ直線 | オレンジ | 傾き＝平均変化率 |
| 接線（x = a） | 青 | 傾き＝微分係数 |
| Δx・Δy の補助線（直角三角形） | オレンジの破線 | |
| 導関数 y = f'(x) | 緑系 | ③で使用 |

- 色だけに頼らず、線種（実線／破線）とラベルでも区別する。
- jimitas 既存の配色・フォント設定があればそれを優先し、上の「役割」を当てはめる。

## 4. 機能要件

優先度：**P0＝必須（スクーリングで使う）／P1＝あると良い（今回入れる）／P2＝余裕があれば**

### 4.1 ステップ① 平均変化率

| ID | 優先 | 要件 |
|---|---|---|
| F1-1 | P0 | グラフ上に点A(a, f(a))、点B(b, f(b)) を表示。どちらもドラッグで x 方向に動かせる（点は曲線上を移動）。 |
| F1-2 | P0 | 2点を結ぶ直線を描画し、グラフ領域の端まで延長する。 |
| F1-3 | P0 | Δx（横の変化）と Δy（縦の変化）を直角三角形の補助線で表示し、それぞれの値をラベル表示。 |
| F1-4 | P0 | 数値パネルに「平均変化率 ＝ Δy ÷ Δx ＝ ○○」を表示。計算の途中式も出す（例：`(4 − 1) ÷ (2 − 1) = 3`。初期値は a = 1・b = 2）。 |
| F1-5 | P0 | a, b をスライダー・数値入力でも設定できる（0.1 刻み、ドラッグ時は 0.1 にスナップ）。 |
| F1-6 | P1 | 「この傾きは2点の位置で変わる」ことに気づかせる一文ガイドを表示。 |

### 4.2 ステップ② 微分係数（**本アプリの核**）

点B を x = a + h として、**h を小さくしていくアニメーション**が主役。教員の実演でそのまま使えることを最優先にする。

| ID | 優先 | 要件 |
|---|---|---|
| F2-1 | P0 | a をスライダー／ドラッグで設定。h をスライダーで設定（範囲 -2〜2、0 は選べない）。 |
| F2-2 | P0 | **「▶ 近づけてみる」ボタン（大きく目立つ位置）**：h を 1 から 0 付近まで連続的に小さくするアニメーション（約5秒）。再生／一時停止／リセット可。再生中は記録表に h = 1, 0.5, 0.1, 0.01, 0.001 を通過した時点の値を順に書き込む。 |
| F2-3 | P0 | **「1段ずつ」ボタン**：h を **1 → 0.5 → 0.1 → 0.01 → 0.001** の順に1段ずつ小さくする。押すたびに直線がアニメーション（0.4〜0.6秒程度のイージング）で動く。説明しながら止めたいとき用。 |
| F2-4 | P0 | **記録表**：列は `h`、`x = a + h`、`f(a + h) − f(a)`、`平均変化率`。初期状態（x², a = 1）で表の値がスライド10–11（3, 2.5, 2.1, 2.01, 2.001）と一致すること。 |
| F2-5 | P0 | **右から・左から**：h > 0（右から）と h < 0（左から）を切り替えるボタン。左からは -1 → -0.5 → -0.1 → -0.01 → -0.001（値 1, 1.5, 1.9, 1.99, 1.999）。両方から同じ値に近づくことを表で並べて見せられる。 |
| F2-6 | P0 | **接線の表示**：「接線を表示」トグル。初期はオフ（先に「どこへ行くか」を予想させるため）。オンにすると x = a の接線を青の破線で表示し、2点を結ぶ直線が接線に重なっていく様子を見せる。アニメーション終了時（|h| ≤ 0.001）に自動でオンにし、接線を実線に切り替えて強調する。 |
| F2-7 | P0 | **追いかけズーム**（オン/オフ、初期オン）：h が小さくなると点B が点A に重なって見えなくなるため、アニメーション中に点A のまわりへ自動で少しずつズームする。拡大すると曲線がまっすぐに見え、2点を結ぶ直線と接線がぴったり重なることを示す。終了後「全体表示に戻す」で元に戻る。 |
| F2-8 | P0 | **h = 0 は選べない理由**を表示：h を 0 にしようとすると「2点が重なると Δx = 0 となり、割り算ができない。だから『近づけた行き先』を考える」というメッセージ。（「極限」という考え方への橋渡し） |
| F2-9 | P0 | 結論パネル：「h を 0 に近づけると、平均変化率は **○○** に近づく。これが x = a における微分係数（接線の傾き）」。「記号で」表示時は `f'(a) = lim_{h→0} (f(a+h) − f(a))/h = ○○`。 |
| F2-10 | P0 | **文字式での確認**（「記号で」表示時、ボタンで1行ずつ段階表示）：`(f(a+h) − f(a))/h` を展開・約分して h の式にし（例：x² なら `2a + h`）、h → 0 で `2a` になる流れを示す。プリセット関数すべてで正しく生成されること（多項式なので自動生成）。 |
| F2-11 | P1 | **拡大ルーペ**：点A のまわりを拡大した小窓を常時表示（追いかけズームとは別に、全体図を見せたまま拡大も見せたいとき用）。 |

### 4.3 ステップ③ 導関数

| ID | 優先 | 要件 |
|---|---|---|
| F3-1 | P0 | 上下2段のグラフ。上：y = f(x) と、x = a の接線。下：横軸 x、縦軸「接線の傾き」。 |
| F3-2 | P0 | a をスライダー／ドラッグで動かすと、下のグラフに点 (a, f'(a)) を打ち、**軌跡を残す**（「残す」オン/オフ、消去ボタン）。 |
| F3-3 | P0 | 「▶ なぞる」ボタン：a を左端から右端まで自動で動かし、軌跡が y = f'(x) のグラフになっていくアニメーション。終わったら f'(x) の式とグラフ（緑）を重ねて表示。 |
| F3-4 | P0 | 説明：「各点での接線の傾きを集めた関数 ＝ 導関数 f'(x)」「x² なら 2x（1なら2、2なら4、3なら6）」。 |
| F3-5 | P0 | **計算のしかた**パネル：公式 `(xⁿ)' = n xⁿ⁻¹`（n = 1, 2, 3）、`(c)' = 0`、`(k f(x))' = k f'(x)`、和・差の微分を示し、選択中の関数について**項ごとに**微分する途中式を表示する。 |
| F3-6 | P1 | **練習問題（導関数）**：3次以下・整数係数の多項式の導関数を求める問題をランダム出題。**問題と答えは同時に出さず**、「答えを見る」ボタンで途中式つきの答えを表示。 |
| F3-7 | P1 | **練習問題（微分係数）**：「f(x) について x = a における微分係数を求めよ」。答えでは「導関数を求めて a を代入」と「グラフ上の接線」を両方見せる（答え表示時にグラフへ接線を描く）。 |
| F3-8 | P1 | **自動採点**：答えを入力して判定。導関数は係数ごとの入力欄（`□x² + □x + □`）で入力させ、式の文字入力パースはしない。正誤と、まちがえた項の指摘を表示。 |
| F3-9 | P2 | 正解数・連続正解の表示（ページ内のみ。保存しない）。 |

## 5. 計算仕様

- 関数はすべて**3次以下の多項式**として内部表現する：係数配列 `[c0, c1, c2, c3]`。
- **差分商は浮動小数点の引き算で計算しない**（`f(a+h) − f(a)` は h が小さいと桁落ちする）。多項式の恒等式で直接計算する：
  - `(f(a+h) − f(a))/h = Σ_k c_k · Σ_{j=0}^{k−1} (a+h)^j · a^{k−1−j}`
  - 表示値は有効数字を考慮して丸め、末尾の 0 は落とす（4.0100 → 4.01）。
- 導関数・文字式展開（F2-10, F3-5）は係数演算で生成する（数式処理ライブラリは不要）。
- 数式表示の書式例：`-x² + 4x`、`x³ − 3x`（係数1は省略、負の項は「−」でつなぐ、0の項は省く）。

## 8. 受け入れ基準（テスト観点）

1. 初期状態（f = x²、a = 1）で②の「1段ずつ」を4回押すと、記録表の平均変化率が **3 → 2.5 → 2.1 → 2.01** と表示される。5回目で 2.001。
2. 同条件で「左から」に切り替えると **1 → 1.5 → 1.9 → 1.99 → 1.999**。
3. 「▶ 近づけてみる」を押すと約5秒で h が 0 付近まで小さくなり、追いかけズームで点A付近が拡大され、終了時に接線が実線で表示される。記録表には5行が書き込まれている。
4. h = 0.001 のとき2点を結ぶ直線と接線がグラフ上で見分けられないほど重なる。
5. h を 0 にしようとしても 0 にならず、F2-8 のメッセージが出る。
6. プリセット全5種で、F2-10 の文字式変形と F3-5 の導関数が正しい（例：`x³ − 3x` → `3x² − 3`、x = 1 での接線は水平）。
7. ③で「なぞる」を実行すると、軌跡が f'(x) のグラフと一致する。
8. 自作関数 `c₃ = 0, c₂ = 0, c₁ = 2, c₀ = 1`（直線）では、h によらず平均変化率が常に 2（2点を結ぶ直線＝接線＝元の直線）。
9. 練習問題で、答えは「答えを見る」を押すまで表示されない。自動採点で正答・誤答が正しく判定される。
10. 画面上に「割線」という語は「記号で」表示時の補足1か所以外に出てこない。
11. iPhone（Safari、縦）で点をドラッグしてもページがスクロールしない。
12. 差分商・導関数・採点判定の関数にユニットテストを用意する（上記1, 2, 6, 8の数値を含む）。
13. `next build` が警告なく通る。

8. **P1**：練習問題（導関数・微分係数）、自動採点、拡大ルーペ、文脈ラベル、大きく表示モード、キーボード操作。
