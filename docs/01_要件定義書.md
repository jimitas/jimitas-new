# 01 要件定義書

## プロジェクト概要

**プロジェクト名**: jimitas.com リニューアル  
**コンセプト**: 「地味に助かる」— 先生と子ども・保護者、両方のための学習アプリポータル  
**一言で言うと**: バラバラに存在しているすべてのアプリを、jimitas.com という一つの玄関口にまとめる（ポータルの一本化）

---

## ユーザー

| ユーザー | 使い方 |
|---|---|
| 子ども・生徒 | 学習アプリを使って練習する |
| 保護者 | 家庭学習のためにアプリを探して使う |
| 先生 | 授業でURLを生徒に共有する・教材プリントを作成する |

---

## 機能要件

### トップページ
- 学年別にアプリがボタンでズラッと並ぶ（ミライシード的なUI）
- アイキャッチ画像なし・シンプル
- 先生向け・子ども向けで入口は分けない
- 以下のグループで構成する

```
１年生
２年生
３年生
４年生
５年生
６年生
中学・高校（将来追加）
音楽・体育・その他
📄 教材作成
```

### アプリページ
- 各アプリは `/apps/[アプリID]` のURLでアクセスできる
- アプリは学年・教科・タグで複数のグループに属せる（タグ方式）

```typescript
{
  id: "tashizan",
  title: "たし算の練習",
  grades: [1, 2],
  subjects: ["算数"],
  tags: ["計算", "タイムアタック"],
  type: "app" // app / print / tool
}
```

### ゲーミフィケーション
- 正解するとコインを獲得できる
- 当面はブラウザのローカルストレージで管理
- 将来的にSupabaseでユーザーごとに管理する

### 教材作成
- じみぷり（算数プリント自動生成）
- 漢字プリント作成
- 今後追加予定

---

## 非機能要件

| 項目 | 内容 |
|---|---|
| 無料アクセス | 認証なし・誰でも無料で使える |
| レスポンシブ | タブレット・PC対応 |
| 表示速度 | WordPressより高速（離脱防止） |
| 収益化 | なし |
| 保守性 | 部品化・再利用できる設計 |
| 拡張性 | 新しいアプリを追加しやすい構造 |

---

## 開発・運用方針

- `jimitas-test.vercel.app` などで並行開発
- 完成したら `jimitas.com` に差し替え（WordPressは廃止）
- ドメイン管理：さくらのドメイン（独立管理・安全）
- DNS切り替えでVercelに向けるだけで移行完了
