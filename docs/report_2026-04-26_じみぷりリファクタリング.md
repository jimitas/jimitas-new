## つまずいたポイント

1. **`replace_all` での名前衝突**
   `shuffleArray` → `shuffled` 一括置換時、ローカル変数名と衝突した。
   → 変数を `picked` にリネームして回避。
   → **学び**: 一括置換前に grep で同名識別子の有無を確認すべき。

2. **import位置の混在**
   Phase 1 で BANGOU import を「旧定数があった行」に置いたため、
   ファイル末尾に import が残った状態に。
   → top に移動して整理。

3. **useEffect で setState は推奨されない**
   React 公式が「Effect は外部システム同期用」と明言。
   → `useState` の初期値関数で初期計算する方が素直。
