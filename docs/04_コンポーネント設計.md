## 部品化の方針

- **同じような機能が2つ以上のアプリに出てきたら部品化する**
- ページ共通部品 → `src/components/common/`
- アプリ内共通部品 → `src/components/ui/`
- 楽器系部品 → `src/components/music/`
- 印刷系部品 → `src/components/print/`
- 共通フック → `src/hooks/`
- アプリ固有の部品 → `src/components/apps/[アプリID]/`

## 1. ページ共通コンポーネント（サイト全体）

### `Header`
- サイト名・ロゴ
- コイン残数の表示（useCoins と連携）

### `Footer`
- コピーライト
- jimitas.com へのリンク

### `AppCard`
- トップページのアプリカード
- タイトル・説明・学年タグを表示
- クリックでアプリページへ遷移

### `GradeSection`
- 学年別のセクション（「１年生」「２年生」…）
- AppCard の一覧を表示

## 2. アプリ内共通コンポーネント

### `AnswerFeedback`
**使うアプリ**: とけい・九九・都道府県・英語系・筆算系など（10アプリ以上）

正解・不正解を伝えるフィードバック表示。

```
props:
  result: "correct" | "incorrect" | null
  correctAnswer?: string  // 不正解時に正解を表示する場合
```

表示例：
- 正解 → 緑のチェック ＋ 効果音
- 不正解 → 赤のバツ ＋ 効果音 ＋ 正解表示

---

### `DifficultySelector`
**使うアプリ**: とけい・わり算の筆算・九九・classroom-english など

難易度・モードをボタンで選択するUI。

```
props:
  options: { label: string; value: string }[]
  value: string
  onChange: (value: string) => void
```

使用例：「やさしい / ふつう / むずかしい」「1の段 / 2の段 / …」

---

### `ScoreBoard`
**使うアプリ**: 九九・英単語・都道府県・時計 など

問題数と正解数をリアルタイム表示するスコア欄。

```
props:
  correct: number
  total: number
  label?: string  // 例：「正解数」
```

---

### `ResultModal`
**使うアプリ**: 九九・英単語・都道府県・時計 など

問題がすべて終わったときに表示する結果画面（モーダル）。

```
props:
  correct: number
  total: number
  onRetry: () => void
  coinsEarned?: number  // コインを獲得した場合
```

---

### `CoinEffect`
**使うアプリ**: おかね・たし算の筆算・かけ算の筆算②・わり算の筆算

正解したときのコイン獲得アニメーション。

```
props:
  amount: number  // 獲得コイン数
  visible: boolean
```

---

### `CountdownTimer`
**使うアプリ**: 授業タイマー（単体）、将来的にタイムアタック系で使う可能性あり

```
props:
  initialSeconds: number
  onEnd?: () => void
  autoStart?: boolean
```

ストップウォッチモードも兼ねる。

## 3. 筆算系コンポーネント

**使うアプリ**: たし算の筆算・ひき算の筆算・かけ算の筆算①②・わり算の筆算（計5アプリ）

筆算はすべて「マス目に数字を1桁ずつ入力する」構造が共通。

### `DigitCell`
筆算のマス目1つ分。数字を1桁入力できるセル。

```
props:
  value: string
  onChange: (val: string) => void
  readOnly?: boolean
  highlight?: "correct" | "incorrect" | "carry"  // 繰り上がり強調など
```

### `HissanLayout`
筆算全体のグリッドレイアウト。DigitCell を並べる枠組み。

```
props:
  rows: number
  cols: number
  children: React.ReactNode
```

> 四則演算で記号（＋−×÷）と区切り線の位置が変わるだけなので、
> 共通レイアウトを使い回せる。

## 4. 音楽系コンポーネント

**使うアプリ**: もっきん・てっきん・けんばん（計3アプリが同じ構造）

### `InstrumentKey`
鍵盤・音板を1つ分表すUI部品。クリック/タッチで音が鳴る。

```
props:
  note: string       // 音の名前（例："ド", "レ"）
  color?: string     // 音板の色（木琴・鉄琴用）
  width?: number
  onPlay: (note: string) => void
```

### `InstrumentBoard`
InstrumentKey を横に並べた楽器全体のレイアウト。

```
props:
  keys: { note: string; label: string; color?: string }[]
  onPlay: (note: string) => void
```

## 5. 印刷系コンポーネント

**使うアプリ**: じみぷり・漢字プリント・九九のひょう・せんやマスのいろぬり（計4アプリ）

### `PrintLayout`
印刷用のレイアウト枠。A4を想定し、`@media print` で余白・フォントを調整。

```
props:
  title?: string
  children: React.ReactNode
```

### `PrintButton`
「印刷する」ボタン。クリックで `window.print()` を呼ぶ。

```
props:
  label?: string  // デフォルト：「印刷する」
```

## 6. 共通フック（Hooks）

### `useCoins`
コイン数の取得・加算。当面は localStorage、将来 Supabase に移行。

```typescript
const { coins, addCoins } = useCoins()
```

**使うアプリ**: おかね・たし算の筆算・かけ算の筆算②・わり算の筆算

---

### `useSound`
音声ファイル（MP3 など）を再生するフック。Howler.js のラッパー。

```typescript
const { play } = useSound("/sounds/correct.mp3")
play()
```

**使うアプリ**: 九九の読み上げ・音楽記号・Classroom English・英単語 など

---

### `useTone`
Tone.js を使って音を生成するフック。楽器系アプリ向け。

```typescript
const { playNote } = useTone()
playNote("C4", "8n")
```

**使うアプリ**: もっきん・てっきん・リコーダー・音を出そう・和音を出そう・メトロノーム

---

### `useTimer`
カウントダウン・ストップウォッチ機能を提供するフック。

```typescript
const { seconds, isRunning, start, stop, reset } = useTimer(60)
```

**使うアプリ**: 授業タイマー、将来のタイムアタック系

---

### `usePrint`
印刷トリガーと印刷前後の状態管理。

```typescript
const { print, isPrinting } = usePrint()
```

**使うアプリ**: じみぷり・漢字プリント・九九のひょう
